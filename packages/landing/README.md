# @swarmwage/landing

Next.js landing page for `swarmwage.com`.

## Run locally

```bash
pnpm install
pnpm --filter @swarmwage/landing dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Create new Vercel project, link to `Swarmwage/swarmwage` GitHub repo
2. Set **Root Directory** to `packages/landing`
3. Framework preset: Next.js (auto-detected)
4. Add custom domain: `swarmwage.com`
5. Optional env: `WAITLIST_DISCORD_WEBHOOK_URL`
